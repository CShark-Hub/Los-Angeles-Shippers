# Mercury

Mercury answers the questions people who don't read code ask about a software project: what is
done, what is tested, what is blocked, how healthy the project is and what changed. It answers from
facts that a probe next to the repository produces, through a gateway that checks every step with a
judge model. No answer can carry code.
